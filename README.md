## Package manager

This project uses **pnpm**. Do not commit `package-lock.json`; the canonical lockfile is `pnpm-lock.yaml`.

### Setup

```bash
corepack enable
corepack prepare pnpm@10 --activate
pnpm install
```

If Corepack is unavailable on your machine, install pnpm 10 directly and then run `pnpm install`.

### Development

```bash
pnpm dev
```

### Build

```bash
pnpm build
```

### Lint

```bash
pnpm lint
```

### Preview

```bash
pnpm preview
```
